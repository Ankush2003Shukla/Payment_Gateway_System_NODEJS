# 💳 Payment Gateway System  

A **Payment Gateway System** integrated with **PayPal**, built to support a small **e-commerce clothing site** where users can browse and purchase products.  
The backend is powered by **Node.js + Express**, while the frontend is crafted with **HTML + CSS** for a smooth shopping experience.  

---

## ✨ Features  

- 🔗 **PayPal Integration** – Seamless payment handling via PayPal REST API.  
- 🛍 **E-Commerce Functionality** – Users can browse and buy clothes easily.  
- 📱 **Responsive Design** – Frontend built with HTML & CSS for a clean user interface.  

---

## 🛠️ Tech Stack  

**Backend:** Node.js, Express  
**Payment Gateway:** PayPal REST API  
**Frontend:** HTML, CSS
